# Эксперименты с рейтингом Elo

Интерактивная лаборатория моделирует рейтинг синтетического пула игроков и
показывает:

- динамику Elo финального топ-10;
- итоговый рейтинг и статистику игроков;
- логистическую кривую ожидаемого результата;
- конечную разницу рейтингов для выбранной практической уверенности;
- чувствительность средней ошибки рейтинга к K-фактору.

Настраиваются K-фактор, масштаб формулы, provisional-множитель и его период,
нижняя граница рейтинга, размер пула, число раундов, разброс истинной силы,
частота ничьих, преимущество белых, уровень уверенности и random seed.

Elo не может дать строго гарантированную победу при конечной разнице рейтингов:
вероятность лишь асимптотически стремится к 100%. Поэтому дашборд использует
настраиваемый порог практической уверенности.

Запуск из корня проекта:

```powershell
.\.venv\Scripts\python.exe experiments\run_elo_dashboard.py
```

Математика находится в `src/chess_core/app/rating/`, интерфейс — в
`src/chess_core/ui/experiments/`. Симуляция детерминирована для одного seed.
