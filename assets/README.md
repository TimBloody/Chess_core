# Assets

Downloaded/created asset sources:

- `lichess/pieces/cburnett/*.svg`: Lichess `cburnett` chess pieces from `lichess-org/lila`, `public/piece/cburnett`.
- `lichess/board/light_square.svg` and `dark_square.svg`: standalone SVG square tiles using the common Lichess brown board colors.
- `lishogi/pieces/standard/shogi_bnw/*`: official Lishogi standard shogi piece set from `WandererXII/lishogi`, `ui/@build/pieces/assets/standard/shogi_bnw`.
- `lishogi/pieces/dobutsu/{lion,giraffe,elephant,chick,hen}.svg`: Lishogi Dobutsu animal set, renamed from upstream `0OU`/`0HI`/`0KA`/`0FU`/`0TO` so keys match piece types. Both sides share one drawing; gote is rotated in the UI (`dobutsu/lion@b`).
- `boardgames/wdisc.svg` and `bdisc.svg`: original draughts-style discs for Reversi, Corners, and Draughts men (not chess pawns).
- `boardgames/wkingman.svg` and `bkingman.svg`: crowned discs for Draughts flying kings, same style as the men.
- `ui/app.ico`: window and desktop-shortcut icon, white Cburnett knight (`wN.svg`) on a dark rounded square.

Check upstream licenses before distributing a packaged executable with these assets.
