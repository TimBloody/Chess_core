# Custom engines

Сюда кладутся **собственные** бинарники и модели для игр, у которых нет сильного открытого движка: двухходовки, duck chess, fairytale и т.п.

Исходники таких движков держите в отслеживаемом пакете (`src/chess_core/...`). В эту папку копируйте только собранный exe и тяжёлые веса.

Пока каталог пустой. Когда появится движок, добавьте подпапку и README по образцу `engines/public/stockfish/README.md`: протокол, команда запуска, пример stdin/stdout и сниппет на Python.
